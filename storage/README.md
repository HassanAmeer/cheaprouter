# Storage Directory

This directory contains application storage folders. **DO NOT DELETE** these folders or their contents.

## Folder Structure

| Folder | Purpose |
|--------|---------|
| `cheap_chats/` | Stores chat-related media files (images, audio, video, documents shared in conversations) |
| `cheap_user_dashboard/` | Stores user dashboard files (profile pictures, avatars, user-uploaded documents) |
| `cheap_web_builder/` | Inactive legacy storage retained to avoid deleting existing user files |

## Guidelines

- These folders are part of the application structure
- Deleting these folders may break file upload functionality
- When implementing file uploads, use the appropriate subfolder based on the feature
